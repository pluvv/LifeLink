# LifeLink — Blood Bank Management System

LifeLink is a Java web application for a university project that simulates blood donation, blood-bank inventory, recipient requests, and blood-bank transfers.

## Planned stack
- Java 17
- Maven
- JSP and Java Servlets (javax.servlet)
- MySQL 8
- JDBC
- Apache Tomcat 9
- Bootstrap 5 / custom CSS

## Planned modules
- Admin: review registrations, manage users, overview dashboard
- Donor: profile, donation appointment booking, appointment history, donation certificate
- Recipient: search stock, request blood, track request status
- Blood bank: stock management, process appointments and requests, bank-to-bank transfers

## Project status
**In development.** Features will be added and tested incrementally. This is an educational simulation only, not a real medical service.
